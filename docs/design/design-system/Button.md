# Button

Use **primary** (`action`) no máximo uma vez por área, para a ação principal; **default** para as demais; **agent** só para pedir algo a um agente ("Pedir à Ada"): botão padrão com o canto vivo e o ícone de agente em `agent`; **danger** para recusar ou excluir; **ghost** em barras de ferramentas. Rótulo começa com verbo. Botão só de ícone exige `aria-label`. O consumidor fornece o rótulo e, opcionalmente, um ícone `ac-icon` antes dele. Tamanhos: padrão 36px, `ac-btn--sm` 28px dentro de cards.
