# Brand logos

The logos of the apps the onboarding's "Bring your agents" step names, the same official files the web app ships in `apps/web/public/brands/` (its README has each file's source and license). The phone draws images, not SVG files, so each SVG is rendered at 96 px:

- `openclaw.png`: `openclaw.svg`;
- `hermes.png`, `hermes-dark.png`: `hermes.svg` and `hermes-dark.svg` (the dark one where the app's theme is dark);
- `openbotrun.png`: `openbotrun.svg`;
- `paperclip.png`, `paperclip-dark.png`: `paperclip.svg` and `paperclip-dark.svg` (the same);
- `openmausbot.png`: `openmausbot.svg`;
- `openbot.png`: copied unchanged (the project has no vector logo);
- `agenteschat.png`: our own mark, `apps/web/public/favicon.svg`, for a file exported from another agentes.chat workspace.

Each logo is a trademark of its owner, used only to name the project.
