# Connector icons

Brand icons for the connector catalog, from [Simple Icons](https://simpleicons.org) 16.32.0 (CC0 1.0, public domain). One single-color SVG per service; the app draws them as a mask in the brand color (or the ink, for near-black or very light brands). Brand colors live with the catalog in code.

Canva and Microsoft Outlook are not in Simple Icons (removed at the brands' request), so they keep the monogram tile. The email cards' colors (Gmail, iCloud) live in `apps/web/src/components/MailConnect.tsx`.

Each icon is a trademark of its owner, used only to name the service.
